# Requirements

At0mFlow Uptime Monitor has no third-party runtime dependencies.

## Supported environments

- Windows PowerShell 5.1 on Windows.
- PowerShell 7.4 or newer on Windows or Linux.
- Network access from the local machine to the endpoints being checked.
- Git is optional and is needed only to clone the repository.

Contributor and CI checks use:

- PSScriptAnalyzer 1.25.0 for static analysis.
- Python 3 for the isolated local HTTP test fixture.

Neither dependency is required to run the monitor.

No At0mFlow account, API key, hosted service or paid dependency is required.
