# Security

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Send
the details through the contact channel at [at0mflow.com](https://at0mflow.com/)
and include `At0mFlow-UptimeMonitor security` in the subject or message.

## Data handling

This tool runs locally. It sends HTTP or HTTPS requests only to endpoints the
user explicitly supplies. Results stay in the console or the local output file
the user requests.

It contains no telemetry, authentication, remote storage, At0mFlow API client,
webhook sender or bundled credentials. Configuration examples contain only
public demonstration URLs.
